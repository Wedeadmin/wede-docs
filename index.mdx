## What is Wede?

Wede is an **offline-first resilience platform** that ensures your mission-critical operations continue even when internet connectivity degrades or fails completely.

Built for healthcare, banking, logistics, and emergency services.

## Quick Start

1. Get your API key from [app.wede.pt](https://app.wede.pt/dashboard/settings)
2. Authenticate via `/v1/auth/token`
3. Send events via `/v1/events`
4. Monitor in real-time in your dashboard

## Base URL

All API requests go to `https://api.wede.pt`
