## JavaScript / TypeScript SDK

The official Wede SDK for JavaScript and TypeScript is available on GitHub.

**Repository:** https://github.com/Wedeadmin/wede-sdk

### Installation

```bash
npm install @wede/sdk
```

### Quick Start

```typescript
import { WedeClient } from '@wede/sdk'

const client = new WedeClient({ apiKey: 'wede_live_YOUR_KEY' })

// Send an event
await client.sendEvent({
  type: 'EMERGENCY',
  priority: 'critical',
  vertical: 'healthcare',
  idempotency_key: 'evt-001',
  payload: { patient_id: 'PT123' }
})

// List zones
const zones = await client.listZones()

// Sync offline batch
await client.syncBatch({
  events: [...offlineEvents],
  device_id: 'device-001',
  captured_at: new Date().toISOString()
})
```

### Available Methods

| Method | Description |
|--------|-------------|
| `sendEvent(event)` | Submit a new event |
| `listEvents(params?)` | List events |
| `listZones()` | List all zones |
| `getZone(zoneId)` | Get a specific zone |
| `syncBatch(batch)` | Sync offline events |
| `getSyncStatus(batchId)` | Get sync batch status |
| `getConnectivityStatus(zoneId)` | Get zone connectivity state |
| `reportConnectivity(report)` | Report connectivity state |
| `listParsers()` | List all parsers |
| `getParser(parserId)` | Get a specific parser |
| `getActiveParser(vertical)` | Get active parser for vertical |
| `createParser(parser)` | Create a new parser |
| `updateParser(parserId, data)` | Update an existing parser |
| `listWebhooks()` | List all webhooks |
| `createWebhook(webhook)` | Create a new webhook |
| `deleteWebhook(webhookId)` | Delete a webhook |
| `getTenantInfo()` | Get tenant details |
| `getUsage(from, to)` | Get usage statistics |

## Python SDK

The official Wede SDK for Python is available on GitHub.

**Repository:** https://github.com/Wedeadmin/wede-sdk-python

### Installation

```bash
pip install wede-sdk
```

### Quick Start

```python
from wede import WedeClient, WedeEvent, WedeSyncBatch
from datetime import datetime, timezone

client = WedeClient(api_key="wede_live_YOUR_KEY")

# Send an event
event = WedeEvent(
    type="EMERGENCY",
    idempotency_key="evt-001",
    vertical="healthcare",
    priority="critical",
    payload={"patient_id": "PT123"}
)
result = client.send_event(event)

# List zones
zones = client.list_zones()

# Sync offline batch
batch = WedeSyncBatch(
    events=[event],
    captured_at=datetime.now(timezone.utc).isoformat(),
    device_id="device-001"
)
result = client.sync_batch(batch)
```

### Available Methods

| Method | Description |
|--------|-------------|
| `send_event(event)` | Submit a new event |
| `list_events(...)` | List events |
| `list_zones()` | List all zones |
| `get_zone(zone_id)` | Get a specific zone |
| `sync_batch(batch)` | Sync offline events |
| `get_sync_status(batch_id)` | Get sync batch status |
| `get_connectivity_status(zone_id)` | Get zone connectivity |
| `report_connectivity(...)` | Report connectivity state |
| `list_parsers()` | List all parsers |
| `get_parser(parser_id)` | Get a specific parser |
| `get_active_parser(vertical)` | Get active parser for vertical |
| `create_parser(...)` | Create a new parser |
| `update_parser(...)` | Update an existing parser |
| `list_webhooks()` | List all webhooks |
| `create_webhook(...)` | Create a new webhook |
| `delete_webhook(webhook_id)` | Delete a webhook |
| `get_tenant_info()` | Get tenant details |
| `get_usage(from_date, to_date)` | Get usage statistics |
