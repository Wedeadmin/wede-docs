## JavaScript / TypeScript SDK

**Repository:** https://github.com/Wedeadmin/wede-sdk

### Installation

```bash
npm install @wede/sdk
```

### Quick Start

```typescript
import { WedeClient } from '@wede/sdk'

const client = new WedeClient({ apiKey: 'wede_live_YOUR_KEY' })

await client.sendEvent({
  type: 'EMERGENCY',
  priority: 'critical',
  vertical: 'healthcare',
  idempotency_key: 'evt-001',
  payload: { patient_id: 'PT123' }
})

const zones = await client.listZones()
const parser = await client.getActiveParser('healthcare')
```

## Python SDK

**Repository:** https://github.com/Wedeadmin/wede-sdk-python

### Installation

```bash
pip install wede-sdk
```

### Quick Start

```python
from wede import WedeClient, WedeEvent

client = WedeClient(api_key="wede_live_YOUR_KEY")

event = WedeEvent(
    type="EMERGENCY",
    idempotency_key="evt-001",
    vertical="healthcare",
    priority="critical",
    payload={"patient_id": "PT123"}
)
result = client.send_event(event)
zones = client.list_zones()
```

## React Native SDK

**Repository:** https://github.com/Wedeadmin/wede-sdk-react-native

Includes a built-in offline queue backed by AsyncStorage. Events captured offline are synced automatically when connectivity is restored.

### Installation

```bash
npm install @wede/react-native-sdk
npm install @react-native-async-storage/async-storage
```

### Quick Start

```typescript
import AsyncStorage from "@react-native-async-storage/async-storage"
import { WedeClient } from "@wede/react-native-sdk"

const client = new WedeClient({
  apiKey: "wede_live_YOUR_KEY",
  storage: AsyncStorage,
})

const result = await client.sendEventOrQueue({
  type: "EMERGENCY",
  idempotency_key: "evt-001",
  vertical: "healthcare",
  priority: "critical",
  payload: { patient_id: "PT123" },
})

if (result.queued) {
  console.log("Offline — event queued locally")
}

// Flush when connectivity restored
const { flushed } = await client.flushQueue()
```

## Swift SDK (iOS / macOS)

**Repository:** https://github.com/Wedeadmin/wede-sdk-swift

Supports iOS 15+ and macOS 12+. Built with Swift concurrency (async/await).

### Installation

Add to your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/Wedeadmin/wede-sdk-swift.git", from: "0.1.0")
]
```

### Quick Start

```swift
import WedeSDK

let client = WedeClient(apiKey: "wede_live_YOUR_KEY")

let event = WedeEvent(
    type: "EMERGENCY",
    idempotencyKey: "evt-001",
    payload: ["patient_id": AnyCodable("PT123")],
    vertical: "healthcare",
    priority: "critical"
)

let result = try await client.sendEvent(event)
let zones = try await client.listZones()
let parser = try await client.getActiveParser(vertical: "healthcare")
```
