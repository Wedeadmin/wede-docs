## Authentication

All API requests require authentication via API key or JWT token. See [Authentication](/authentication) for details.

- **API keys** — for server-to-server integrations
- **JWT tokens** — for user sessions and dashboard access
- Tokens expire after **8 hours**
- API keys can be rotated at any time from the [dashboard](https://app.wede.pt)

## Transport Security

All communication with the Wede API is encrypted over HTTPS (TLS 1.2+). Unencrypted HTTP requests are rejected.

## Role-Based Access Control

Wede uses a 7-level cascading RBAC model. No level can grant more than it has. No level can delegate what it has not been explicitly permitted to delegate. Privilege escalation is mathematically impossible.

| Level | Role | Access |
|-------|------|--------|
| 1 | `wede_global_admin` | Full platform control — infrastructure, algorithms, billing, security, all tenants |
| 2 | `wede_tech_ops` | Devices, sync, logs, API — no billing, no tenant config |
| 3 | `country_admin` | Regional management — operators, teams, SLAs, zones by country |
| 4 | `company_admin` | Full tenant access — teams, events, dispatch, billing |
| 5 | `company_tech` | SDK, API keys, integrations, webhooks, parsers — no operational management |
| 6 | `operational_supervisor` | Events, dispatch, teams, zones — no configuration |
| 7 | `field_operator` | Receive missions and submit feedback only — minimum access |

### Cascade principle

- Wede Global Admin defines the full universe of available features
- Each level receives a subset of the level above
- Each level may or may not have permission to delegate each received feature
- Delegation is explicit — not included by default
- Example: Wede activates emergency dispatch for a tenant without delegation — the tenant uses it but cannot grant it to sub-users

## Data isolation

Every tenant's data is isolated at the database level by `tenant_id`. No tenant can access another tenant's data regardless of role.

## Demo mode

Users without a tenant association operate in `demo_mode: true`. They see static demo data only. Demo mode never affects production data. Tenants with an active account always use production. These are two completely separate worlds.

## Payload opacity

Wede never inspects event payloads. The client encrypts — Wede transports. This is a design principle, not a configuration option.
